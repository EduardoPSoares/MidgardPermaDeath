# rPermadeath

Plugin de morte permanente para servidores de roleplay (Paper), com replay da morte do jogador.

## Destaques

- Morte permanente com regras configuráveis e integração com LuckPerms, Vault, MMOCore, WorldGuard e ReviveMe.
- **Replay de morte**: grava os últimos momentos do jogador (movimento, eventos, pacotes) e reproduz a cena num
  mundo vazio isolado.
- **Áudio no replay**: captura a voz do Simple Voice Chat e toca junto na reprodução.
- Placeholders (PlaceholderAPI), webhook do Discord e persistência em banco.

## Stack

Java 21 · Gradle · Paper API · LuckPerms · Simple Voice Chat API · PlaceholderAPI

## Comandos

`/rdeath` · `/replaytoggle`
